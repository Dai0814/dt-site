# D & T 情侣主页

这是一个纯静态网站，包含登录页、首页、故事页、相册页和愿望页。

## 本地访问

当前电脑启动静态服务后，同一 Wi-Fi 下可以访问：

```text
http://192.168.31.177:5500/
```

## 公网访问

如果要让任何人、任何品牌设备都能打开，需要把整个目录上传到公网静态托管平台，例如 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或自己的服务器。

需要上传的文件：

```text
index.html
login.html
story.html
daily.html
notes.html
travel.html
album.html
wishes.html
styles.css
script.js
README.md
```

上线后，别人只需要打开托管平台给出的 HTTPS 网址即可。
